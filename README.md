# SharePal Gaming Gadgets — Frontend Assignment

A responsive React/Vite recreation of SharePal's Bangalore Gaming Gadgets rental page.

## Stack
- React + Vite
- Lucide React icons
- CSS responsive layout
- Product data supplied in `public-product-list.json`

## Features
- SharePal-style navigation and Bangalore selector
- Rental date modal
- Gaming category tabs
- Product grid driven by supplied JSON
- Search and sorting
- Wishlist interaction
- Add-to-cart drawer
- FAQ accordion
- Testimonials carousel
- Trust/impact sections
- Responsive mobile/tablet/desktop layouts

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deployment
The project is ready for Vercel, Netlify, or any static Node/Vite host. Set the build command to `npm run build` and output directory to `dist`.

## Assignment note
This implementation uses SharePal's public visual language and publicly accessible product imagery for the recreation. The supplied product JSON is used as the source for the rental catalog.
